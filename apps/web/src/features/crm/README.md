# CRM Feature Module

Enterprise Customer Relationship Management (CRM) module for EAIMOS.

## Sub-modules
- `contacts/`: Individual contact management.
- `companies/`: B2B Organization & Account management.
- `deals/`: Sales pipeline, stage tracking & revenue forecasting.
- `activities/`: Calls, meetings, and interaction logs.
- `automation/`: Lead routing and workflow automation rules.

## Public APIs
Exported via `index.ts`.
