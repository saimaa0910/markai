## 5. Foreign Key Validation Matrix

- **Total Foreign Keys**: `331`
- **Integrity Status**: `100% Validated`. Every foreign key constraint targets a valid, existing table and primary key column (`id`).
- **ON DELETE Behavior**:
  - `CASCADE`: Used for tightly coupled child entities (e.g. `prompt_versions.prompt_id`, `user_organizations.organization_id`, `document_chunks.document_id`).

## 15. Resolved Issues & Fixes Applied During Audit

1. **Missing `version` on `PromptVariable`**: Fixed by renaming relationship `version` to `prompt_version`, restoring inherited `version: Mapped[int]` column from `Base`.
2. **`Base.metadata` Attribute Reserved Keyword**: Fixed in `PlatformEvent` by mapping DB column `"metadata"` to Python attribute `event_metadata`.
3. **`AmbiguousForeignKeysError` on `User.memberships`**: Added explicit `foreign_keys="[UserOrganization.user_id]"` on `User.memberships`.
4. **Mismatched `back_populates` on `Deal.company` and `Deal.contact`**: Added `deals` relationships on `Company` and `Contact` models and updated `Deal` `back_populates="deals"`.
5. **SQLite Dialect Compilation Errors for PostgreSQL Types**: Added `@compiles` handlers for `JSONB`, `ARRAY`, and `UUID` on SQLite in `alembic/env.py` and `tests/conftest.py`.
