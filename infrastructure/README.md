# Enterprise Infrastructure & IaC Blueprints

This directory contains enterprise infrastructure configuration, Terraform / CloudFormation templates, and Kubernetes manifests for EAIMOS.

## Subdirectories
- `docker/`: Docker container definitions and compose specs (see also `/infra/docker`).
- `k8s/`: Helm charts and Kubernetes deployment manifests.
- `terraform/`: Infrastructure-as-code modules for AWS/GCP/Azure.
